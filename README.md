## Featured Projects

### 📈 [Stock Scanner](https://github.com/mnoorzai21/stock-scanner) · [Live Demo](https://mnoorzai21.github.io/stock-scanner/)
A real-time momentum scanner that checks about 10,000 U.S. stocks every minute against five trading filters (price, % gain, relative volume, share float, and fresh news) and sends sound and desktop alerts.
- **React, Vite, Node.js, Express**, Alpaca and Massive market data APIs
- Background scanning with server-side caching, batched API requests, retry handling for rate limits, and flags for unreliable float data
- Automated tests with Node's test runner, plus CI and deployment through GitHub Actions, GitHub Pages, and Render

### 📚 [Book Search](https://github.com/mnoorzai21/book-searchjet-mnn) · [Live Demo](https://mnoorzai21.github.io/book-searchjet-mnn/)
Search the Google Books catalog, create an account, and keep a personal reading list.
